## 🚀 How to Run

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/Python-Lab-Exercises.git
cd Python-Lab-Exercises
```

### 2. (Optional) Install dependencies (only needed for Lab 5 Mini Project)
```bash
pip install -r requirements.txt
```

### 3. Run any program
```bash
python Lab_Exercise_1/01_basic_program.py
python Lab_Exercise_5/Mini_Project/retail_sales_dashboard.py
```
